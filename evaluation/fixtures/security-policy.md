# Information Security Policy

Policy SEC-104 requires every employee to rotate their account password every 90 days.
Remote access requires multi-factor authentication. Suspected credential exposure must be
reported to the security team within one hour.

制度 SEC-104 要求每位员工每 90 天轮换一次账户密码。远程访问必须使用多因素认证。
发现凭证可能泄露时，必须在一小时内报告安全团队。
