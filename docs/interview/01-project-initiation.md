# 第 1 步面试题：项目立项与范围

## 1. 什么是检索增强生成？为什么企业知识库需要它？

**参考答案：** 检索增强生成是在回答问题时，先从企业自己的文档中检索相关片段，再把问题和片段一起交给大语言模型生成答案。它可以使用模型训练数据之外的私有或较新知识，并通过来源引用提高可核验性。但它不能自动消除所有错误，所以还需要权限过滤、拒答策略、引用校验和质量评测。

## 2. 这个项目解决的核心业务问题是什么？

**参考答案：** 企业资料分散且搜索成本高，普通关键词搜索不理解自然语言，直接使用大语言模型又无法可靠访问私有资料。本项目让有权限的员工用自然语言查询内部文档，并得到带原文证据的答案，同时让管理员能审计和评测系统效果。

## 3. 为什么不一开始采用微服务？

**参考答案：** 当前团队规模小、业务边界仍在验证。微服务会引入服务发现、网络故障、分布式事务、独立部署和监控等额外复杂度。模块化单体能以较低成本建立清晰边界和完整测试，等某个模块出现独立扩缩容或团队协作需求时再拆分，风险更低。

## 4. “企业级”不只是功能多，它还意味着什么？

**参考答案：** 企业级更强调安全、权限、稳定性、可维护性、可观测性、审计、数据备份、失败恢复、测试、发布流程和效果证据。一个能回答问题的演示不是企业级系统；系统还必须能安全运行、定位故障、控制变更并证明质量。

## 5. 为什么必须明确第一版不做什么？

**参考答案：** 时间和资源有限。如果没有范围边界，需求会不断增加，导致核心流程迟迟不能交付。明确排除项可以优先完成最有业务价值的端到端闭环，并为后续版本保留清晰计划。

## 6. 如何证明项目效果，而不是只展示漂亮页面？

**参考答案：** 建立固定且版本化的文档数据集和问题集，保存每次实验的配置、逐题原始结果和汇总指标。分别评测检索是否找到正确证据、回答是否忠于证据，并记录延迟和资源消耗。指标必须来自可复现实验，不能先写结论再凑数据。
