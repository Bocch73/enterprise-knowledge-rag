# 第 7 步面试题与参考答案：分块与向量写入

建议按“原理 → 本项目实现 → 取舍与验证”回答。

## 1. 为什么不能直接对整篇文档生成一个向量？

**参考答案：** 整篇文档可能包含多个主题，一个向量会把不同内容混合，检索后也无法给出精确证据。本项目按自然边界切成最多 800 字符的片段，保存原文位置，使检索和引用都落到具体内容。整篇摘要向量可以作为未来的多粒度补充，但不能替代细粒度片段。

## 2. 分块大小怎样选择？

**参考答案：** 没有适合所有文档的固定答案。片段过大包含无关内容，过小丢失上下文并增加向量数量。本项目先以 800 字符和 120 字符重叠建立可重复基线，后续在固定评测集上比较不同配置的召回率、答案质量、延迟和成本。

## 3. 重叠窗口解决什么问题？代价是什么？

**参考答案：** 它让边界附近文字同时出现在相邻片段，降低一个完整事实被切开的风险。代价是重复内容、更多向量、更多存储以及检索结果可能出现相似重复片段，所以后续还要做去重或父文档聚合。

## 4. 为什么保存 start_offset 和 end_offset？

**参考答案：** 它们把片段映射回解析全文。项目可以验证片段确实等于原文切片，生成引用时也能定位证据。只有片段文本而没有位置，文档更新、审计和引用高亮会更困难。

## 5. 什么是向量维度？

**参考答案：** 维度是向量包含的数字个数，由向量模型结构决定。本项目固定使用 384 维，并在代码和数据库同时校验。切换到不同维度模型不是只改配置，需要迁移列、重新生成全部向量并重新评测。

## 6. 为什么要使用 Provider 抽象？

**参考答案：** 分块和任务编排只依赖“批量文本转固定维度向量”的小接口，供应商认证、网络和格式转换留在适配器中。自动化测试可以注入离线替身，切换模型也不需要修改业务状态机。这是依赖倒置，而不是为了抽象而抽象。

## 7. 当前确定性哈希向量是语义模型吗？

**参考答案：** 不是。它根据词语和字符对稳定构造向量，只用于验证批处理、维度、数据库写入、距离运算和幂等性。它不能可靠理解同义表达，因此项目明确禁止用它声称语义检索效果；接入真实模型后必须重新生成和评测。

## 8. pgvector 和 pgvector-python 有什么区别？

**参考答案：** pgvector 0.8.6 是安装在 PostgreSQL 服务器中的扩展，提供 `vector` 类型、距离运算符和索引方法。pgvector-python 0.5.0 是 Python 映射库，让 SQLAlchemy 能声明、写入和查询该数据库类型。两者位于不同层，版本号也不需要相同。

## 9. 为什么暂时不创建分层可导航小世界图索引？

**参考答案：** 当前数据规模小，还没有检索评测基线。精确扫描能提供正确的距离排序，便于先验证质量。近似索引会增加内存、构建和参数调优成本，还可能损失召回；项目将在有真实向量数量、延迟和召回数据后再决定。

## 10. 怎样保证任务不会留下半套向量？

**参考答案：** 解析结果、旧片段删除、新片段插入和任务完成状态在一个 PostgreSQL 事务中提交。维度、数量或写入任一失败都会回滚，任务转为失败而不是显示完成。向量生成发生在事务外，避免长时间占用数据库锁。

## 11. 怎样保证重复执行幂等？

**参考答案：** 同一文档版本只有一个任务；重做时先在事务内删除该版本旧片段，再写入完整新集合。片段编号由版本编号、顺序和内容指纹稳定生成，数据库还对版本与片段序号建立唯一约束，所以重复执行不会累积重复记录。

## 12. 为什么 API 不返回 embedding 数组？

**参考答案：** 384 个浮点数对普通用户不可读，会显著增大响应，也暴露内部模型数据。接口只返回片段内容、位置、指纹、模型名称和维度。检索服务在数据库内部使用向量，诊断时通过受控管理工具查看。

## 13. 历史文档怎样获得新增向量？

**参考答案：** 迁移识别过去已经完成解析的任务并重新排队。升级后的工作进程重新读取不可变源文件，生成片段和向量。这个回填过程保留原任务审计字段和次数，生产大规模环境则应使用分批、限速、可暂停的专门回填作业。

## 14. 字符分块有什么不足？

**参考答案：** 字符数不等于模型令牌数，也不了解标题层级、表格、代码块和页面。本项目选择它作为中英文可预测的第一版。后续可以加入模型分词器、Markdown 标题、PDF 页面和 DOCX 段落信息，但必须用评测证明复杂度带来收益。

## 15. 如何证明本步真正完成？

**参考答案：** 两个数据库都启用了 pgvector 0.8.6，迁移 `20260828_0003` 创建了 `vector(384)` 列。50 个测试验证分块边界、重叠、确定性向量、权限、数据库距离和重复处理，分支覆盖率 82.33%；Alembic 无漂移，Ruff 和 Mypy 通过。同时文档明确记录本地向量不代表真实语义效果和暂未创建近似索引。
