# 第 4 步面试题与参考答案：后端最小骨架

回答时不要只背定义，建议按“它是什么 → 本项目怎么做 → 为什么这样取舍”三段表达。

## 1. 为什么选择 FastAPI？

**参考答案：** 本项目需要大量数据接口，并且后续存在异步的模型调用和检索调用。FastAPI 基于 Python 类型声明完成请求和响应校验，还能自动生成 OpenAPI 接口说明，适合前后端协作。Python 的人工智能生态也便于后续接入文档解析、向量模型和生成模型。框架只是基础，企业能力仍需要自己补充配置、错误规范、日志、权限和测试。

## 2. FastAPI 和 Uvicorn 分别做什么？

**参考答案：** FastAPI 是应用框架，负责路由、参数校验、依赖注入和响应模型；Uvicorn 是异步服务器，负责监听端口、接收网络请求，并通过异步服务器网关接口把请求交给应用。可以类比为 FastAPI 定义业务接待流程，Uvicorn 负责打开大门并接待网络连接。

## 3. 什么是应用工厂，为什么不用一个全局应用写到底？

**参考答案：** 应用工厂是创建和配置应用实例的函数。本项目的 `create_app` 统一注册日志、中间件、异常处理器和路由。测试可以注入测试配置并创建隔离实例，避免测试相互污染；未来增加数据库生命周期时也有唯一组装入口。模块级应用仍然保留给服务器加载，但它来自同一个工厂。

## 4. 配置为什么使用环境变量？

**参考答案：** 代码在开发、测试和生产环境应保持相同，变化的是日志级别、服务地址和密钥等配置。环境变量能让部署环境提供这些值，避免为每个环境修改代码。项目还用数据模型校验类型和范围，并禁止生产环境开启调试模式。真实密钥只放本地 `.env` 或生产密钥管理系统，不能提交到版本库。

## 5. 中间件是什么？本项目为什么用它？

**参考答案：** 中间件是所有请求和响应都会经过的公共处理层，适合与具体业务无关但每个接口都需要的能力。本项目用纯异步服务器网关接口中间件生成或校验请求编号、添加响应头、统计耗时、记录结构化日志并兜底未知异常，因此业务接口不用重复写这些逻辑。

## 6. 请求编号有什么价值？它能当用户身份吗？

**参考答案：** 请求编号用于关联一次请求在响应、访问日志和异常日志中的记录。用户报告问题时提供编号，工程师可以快速定位。它不能作为身份或权限凭据，因为调用方可能自行提供，且编号只表示请求相关性，不证明是谁发起请求。

## 7. 为什么使用结构化日志？

**参考答案：** 自由文本日志很难稳定解析。结构化日志为时间、级别、请求编号、路径、状态码和耗时提供固定字段，日志平台可以按字段检索、聚合和告警。本项目输出 JSON，并使用上下文变量让并发请求各自取得正确的请求编号。

## 8. 存活检查和就绪检查有什么区别？

**参考答案：** 存活检查判断进程是否还能工作，失败通常触发重启；就绪检查判断当前是否可以接收业务流量，数据库等必要依赖故障时会失败，入口层应暂停转发流量，但不一定重启进程。存活检查不应依赖数据库，否则数据库故障会造成所有应用反复重启，扩大影响。

## 9. 为什么要统一错误响应？

**参考答案：** 如果每个接口错误格式不同，前端会写很多分支且难以维护。项目统一返回机器可读错误码、人类可读信息、请求编号和可选细节。已知业务错误可以安全展示，未知异常只返回通用信息，堆栈和内部路径只记录在服务端，兼顾稳定契约和安全性。

## 10. 依赖输入文件和锁文件有什么区别？

**参考答案：** 输入文件记录团队主动选择的直接依赖，便于评审；锁文件还包含解析后的全部间接依赖准确版本，用于不同机器重复安装。本项目分开生产锁文件与开发锁文件，生产环境不需要安装测试和格式工具。升级依赖时修改输入文件、重新解析并跑完整测试，而不是直接改生成的锁文件。

## 11. 单元测试覆盖率 96.79% 能否证明系统质量很好？

**参考答案：** 不能。覆盖率只说明哪些代码被执行过，不保证断言正确，也不代表场景完整。它适合作为发现测试空白和防止覆盖率倒退的门槛。本项目除覆盖率外还测试成功路径、依赖失败、非法请求编号、统一错误和异常信息隐藏，并结合代码规范、类型检查和真实 HTTP 启动验证。

## 12. Ruff、Mypy 和 Pytest 的职责有什么不同？

**参考答案：** Pytest 运行代码验证行为；Ruff 在不运行程序的情况下检查代码规范、潜在错误和格式；Mypy 根据类型声明检查参数与返回值是否一致。三者发现的问题类型不同，组合使用比单一工具更可靠。本项目把三者放进可重复运行的验证脚本，并设置 80% 的分支覆盖率门槛。

## 13. 为什么网络接口使用异步函数？

**参考答案：** 后续检索增强生成会等待数据库、模型服务和对象存储等输入输出操作。异步函数在等待期间可以把执行机会让给其他请求，提高单进程处理并发等待任务的能力。但它不会让中央处理器密集计算自动变快；重型解析和向量计算仍应交给异步任务工作进程。

## 14. 如何解释本步骤的企业开发流程？

**参考答案：** 先从已确认的需求和架构中抽出后端基础能力，固定直接依赖和间接依赖，然后实现配置、错误、日志、追踪与健康检查。每项能力都有成功和失败测试，随后执行格式、规范、严格类型和覆盖率门禁，最后真实启动并通过网络验证，再记录教程、证据和技术债。代码写完不是完成，可重复验证通过才是完成。
