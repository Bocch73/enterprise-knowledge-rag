# 面试交付材料

建议按以下顺序使用：

1. 先阅读[简历描述与自我介绍](resume-and-introduction.md)，形成项目主线。
2. 再阅读[架构答辩手册](architecture-defense.md)，理解每个选择的原因和代价。
3. 面试前一天按[演示脚本](demo-script.md)完整排练两次。
4. 面试当天按[最终交付检查清单](final-delivery-checklist.md)逐项确认。
5. 使用[综合面试题](../interview/14-project-defense.md)随机抽题练习。

所有数字都来自项目内真实验收，不应脱离样本规模和运行环境单独使用。
