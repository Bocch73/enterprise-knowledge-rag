# 第 8 步知识点总结：混合检索

## 你现在应该能讲清楚的主线

系统在通过知识库成员权限检查后，同时执行 pgvector 精确余弦距离检索和 PostgreSQL 全文检索。每路先取得候选名次，再用倒数排名融合生成统一排序。数据库查询只允许访问指定知识库，并且每个逻辑文档只选择最新处理成功版本，因此新版本处理中不会把半成品暴露给用户。

## 十个核心知识点

1. 向量和关键词检索擅长不同问题，混合路线能减少单路盲区。
2. 原始分数量纲不同，不能未经验证直接相加。
3. 倒数排名融合根据名次计算，简单、稳定且可解释。
4. 候选数量影响召回、延迟和后续重排成本。
5. `tsvector` 是文档搜索表示，`tsquery` 是结构化搜索条件。
6. 存储生成列让全文表示始终与片段原文一致。
7. 广义倒排索引是 PostgreSQL 推荐的全文检索索引。
8. 权限过滤必须在两条召回查询中保持同一边界。
9. 最新上传不等于最新可用，检索应选择最新成功版本。
10. 可运行链路不等于效果优秀，真实语义能力必须由真实模型和评测集证明。
