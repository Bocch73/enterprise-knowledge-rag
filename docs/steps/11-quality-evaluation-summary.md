# 第 11 步知识点总结：RAG 质量评测

## 完成的工程能力

- 建立版本化、严格校验的人工评测集。
- 同时覆盖可回答问题和必须拒答的问题。
- 实现命中率、精确率、召回率、平均倒数排名和归一化折损累计增益。
- 实现引用准确率、引用召回率、关键事实覆盖率、拒答准确率和有依据回答率。
- 输出逐题结果、聚合结果、延迟百分位和质量门禁判断。
- 支持免费检索实验、本地确定性完整实验和已授权的外部模型实验。
- 使用只允许 `_test` 后缀数据库的参考实验，避免误操作业务数据。

## 最重要的判断方法

- 命中率低：先修检索，不要只改提示词。
- 命中率高但排名低：调整融合、候选数量或重排。
- 排名好但答案差：检查上下文裁剪、提示词、模型和引用校验。
- 召回高但精确率低：上下文包含噪声，可能增加成本并干扰生成。
- 拒答差：知识库边界不可靠，企业风险往往高于答得不够流畅。
