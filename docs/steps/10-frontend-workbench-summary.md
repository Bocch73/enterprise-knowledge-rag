# 第 10 步知识点总结：Vue 企业工作台

## 你现在应该能讲清楚的主线

浏览器加载 Vue 单页应用，未登录用户只能进入登录和注册页。Pinia 在当前标签页保存访问令牌与用户，路由守卫控制页面导航。工作台通过统一网络层访问知识库、文档和任务接口，上传后轮询摄取进度；问答使用 Fetch 流读取后端服务器发送事件，逐段展示经过校验的答案，最后展开结构化引用。开发环境由 Vite 把同源 `/api` 请求代理到 FastAPI，生产构建输出静态资源。

## 十五个核心知识点

1. 前端负责体验，后端始终负责真实权限与数据安全。
2. 单页应用由前端路由切换视图，不代表只有一个业务页面。
3. Vue 组件通过属性接收数据、通过事件向父组件通知变化。
4. TypeScript 把后端响应字段变成可静态检查的契约。
5. Pinia 只保存必要跨页面状态，不长期复制服务器真相。
6. 访问令牌放会话存储比长期本地存储更短暂，但仍需防御脚本窃取。
7. 路由守卫改善导航体验，不能代替 FastAPI 权限检查。
8. 统一网络层负责认证头、内容类型、错误码、请求编号和流解析。
9. multipart 文件上传的边界由浏览器生成，不能手工写固定内容类型。
10. 轮询适合当前简单任务状态，但大规模系统可评估推送机制。
11. 服务器事件可能跨网络块，解析器必须保留不完整缓冲区。
12. 没有 `done` 事件的流不能标记为完整成功。
13. Vite 开发代理让浏览器保持同源，避免开放过宽跨域策略。
14. 响应式布局和可访问性不是最后美化，而是界面验收的一部分。
15. 单元、组件、端到端和真实联调分别证明不同层次，不能互相完全替代。
