# 架构决策记录索引

架构决策记录用于保存重要技术决定的背景、候选方案、最终选择和后果。它不是证明某个技术永远最好，而是说明在当时约束下为什么做出该选择。

状态说明：

- **Proposed**：已提出，仍在讨论。
- **Accepted**：已接受，当前实现必须遵守。
- **Superseded**：已经被新的决策替代。
- **Deprecated**：不再推荐，但旧实现可能仍存在。
