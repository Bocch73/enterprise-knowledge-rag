# ADR-0003：使用混合检索和倒数排名融合

- 状态：Accepted
- 日期：2026-08-26
- 决策者：项目开发者

## 背景

企业问题既包含需要语义理解的自然语言，也包含制度编号、产品型号、人名和缩写等必须精确匹配的词语。单独使用向量或关键词都存在明显盲区。

## 候选方案

1. 仅向量检索。
2. 仅关键词全文检索。
3. 两路检索后直接把分数相加。
4. 两路检索后使用倒数排名融合，并可选重排。

## 决定

默认使用关键词和向量两路召回，通过倒数排名融合生成统一候选排名。重排作为可选第二阶段，不默认假设它一定提升效果。

## 原因

- 关键词检索擅长编号、专有名词和原文词语。
- 向量检索擅长同义表达和自然语言语义。
- 两路原始分数范围不同，直接相加需要脆弱的人工归一化。
- 倒数排名融合主要依赖名次，简单、可解释且便于建立基线。
- 重排会增加延迟和成本，必须通过正式评测决定是否启用。

## 后果

积极后果：覆盖更多问题类型，并能展示每个阶段的排名和分数。

代价：一次查询需要两路召回，参数和评测维度增加；权限过滤必须在两路中保持一致。

## 重新评估条件

- 正式数据集证明某一路持续无收益。
- 倒数排名融合显著差于经过验证的学习排序或加权方案。
- 延迟目标要求减少检索阶段。
